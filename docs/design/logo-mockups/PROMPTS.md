# swarmdash logo mockups

Created with the built-in image generation tool. These are raster concept boards for review, not production vector assets.

Each board shows a wordmark, desktop app icon, dark UI application and monochrome symbol. The existing project palette and typography informed the prompts. Stackline was selected; the production SVG assets and regeneration instructions are documented in [branding.md](../branding.md).

- [01 / Stackline](01-stackline.png): an evolution of the current container-stack mark.
- [02 / Swarm Link](02-swarm-link.png): an alternative direction using connected container nodes.
- [03 / Trace S](03-trace-s.png): a log-line monogram, with a terminal-like dash.

## Generation prompts

### 01 / Stackline

```text
Use case: logo-brand.
Asset type: a polished square logo identity mockup board for swarmdash, an open-source desktop dashboard for observing Docker Swarm and Compose and reading complete multiline stack traces. It connects locally or over SSH and is read-only toward Docker.
Design context: the existing UI uses Plus Jakarta Sans, teal #0d8a86, mint #2fd0bd, near-black #0a0f13, and off-white #f2f5f7. The existing icon has four rounded white container squares (one centered above three) over a short horizontal dash, on a teal rounded-square tile.
Create a crisp, professionally art-directed 1536x1536 square brand presentation with generous whitespace, strong alignment, restrained typography, flat vector-like edges and consistent repeated logo geometry. This is a proposal board, not a photograph.
Composition: a small concept title in the top-left; the upper half is an expansive off-white field featuring a large symbol and the exact lowercase wordmark "swarmdash" in a confident geometric sans similar to Plus Jakarta Sans. The bottom half contains three clean aligned applications: a large teal desktop app icon tile, a near-black mini app-sidebar header with the mark and wordmark, and a monochrome small-size symbol study on white. Keep these application studies visually substantial and uncluttered. Use the SAME proposed symbol in every application.
The wordmark must spell "swarmdash" exactly (s w a r m d a s h). Use only the supplied concept title, "swarmdash", and the small application labels "App icon", "Dark UI", and "Small sizes". No extra slogans, body copy, decorative gibberish, external brands, Docker whale, Kubernetes wheel, gradients, shadows, perspective devices, stock mockup props, or watermarks.
Concept title (verbatim): "01 / Stackline".
Primary request: a refined evolution of the existing container-stack identity. Design a highly legible compact symbol of three slightly rounded modular container blocks on a row, one matching block centered above, and one short sturdy horizontal dash below. Carefully tune the spacing, corner radius, and proportions to feel purposeful and balanced rather than generic. The dash suggests both dashboard and a stable overview of the stack. In the main light lockup the freestanding mark is teal; in the teal app icon tile it is white; in the dark UI it is mint; the monochrome study is solid near-black. The brand should feel calm, precise, practical and recognizably connected to the current icon.
```

### Trace S refinement

The third concept was edited with its initial generated board as the reference image. The saved `03-trace-s.png` is the refined result.

```text
Use case: precise-object-edit / logo-brand.
Edit the supplied "03 / Trace S" brand mockup board. The current symbol reads as a reversed S. Change ONLY the proposed symbol, consistently in all four occurrences (large teal mark, white app-icon mark, mint Dark UI mark, black Small sizes mark), to read as an unmistakable standard Latin uppercase S.
The top horizontal stroke must extend toward the RIGHT from a curved return on the LEFT. The middle stroke must lead to the curved return on the RIGHT, and the bottom stroke must finish toward the LEFT. This can be achieved by horizontally mirroring the core three-stroke shape only. Keep the detached short dash on the RIGHT of the bottom of the letter as a terminal/log cursor.
Preserve the existing thick weight, subtle rounded corners, generous negative space, colors, sizes, visual placement and overall proportions. Preserve every other part of the board exactly: text "03 / Trace S", "swarmdash", "App icon", "Dark UI", "Small sizes", typography, panel layout, whitespace, backgrounds and app icon tile. Do not mirror or modify any text. No additional elements.
```
